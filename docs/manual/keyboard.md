# Keyboard

Everything in Blitter works from the keyboard. Menu commands act on the active side. The File
and Edit menus' action shortcuts can be changed in the settings file
([Tools and menus](tools-and-menus.md#the-menu-bar)); the
[default shortcuts](reference/shortcuts.md) page lists them as they come.

## Sides and navigation

| Keys | |
|---|---|
| Tab | switch the active side |
| Return | open the selected folder or file |
| ⌘↑ | enclosing folder |
| ⌘[ / ⌘] | back / forward |
| ⇧⌘G | type a path into the active side's path field |
| Escape | in the path field: drop what was typed |
| ⌘R | read the folder again |
| ⇧⌘. | show or hide hidden files |

## In the list

| Keys | |
|---|---|
| letters | [fast filter](file-list.md#the-fast-filter): highlight matching names |
| `*` then letters | fast filter: list only matching names |
| ↓ / ↑ | while highlighting: next / previous match |
| ⌫ / Escape | fast filter: remove a character / end it |
| Space | Quick Look |
| ⌘A | select all |
| ⌥⌘A | select by pattern |
| ⌃↩ | the context menu (also in the tree) |
| ⌘F | [Find](find.md) below the active side's folder |

## Files

| Keys | |
|---|---|
| F5 / F6 | copy / move the selection to the other side |
| ⌘C / ⌘V | copy items to the clipboard / copy them here |
| ⌥⌘V | move the clipboard's items here |
| ⌥⌘C / ⌥⇧⌘C | copy the selection's paths / names as text |
| ⇧⌘N | new folder |
| F2 / ⇧F2 | rename / batch rename |
| ⌘⌫ | move to the Trash |
| ⌥⌘⌫ / ⌥⇧⌘⌫ | delete immediately, asking first / without asking |
| ⌥⌘S | calculate folder sizes |
| ⌥⌘D / ⌥⇧⌘D | compare files / compare the two sides' folders |
| ⌥⌘R | reveal in Finder |

## View and settings

| Keys | |
|---|---|
| ⌘+ / ⌘− / ⌘0 | larger / smaller / default font size (also Ctrl + mouse wheel) |
| ⌘, | Settings… |
| ⌘S | in Settings: save |
